# Demo video

`tina-demo.mp4` - 2:02, 1280x720, narrated.

**What it is, honestly:** a reconstruction, not a live screen capture. Every terminal
line in it is copied from the committed runs in `../evidence/`; the frames were rendered
from those logs and narrated with a synthetic voice. Nothing in it is invented, and
nothing in it is a live session. If a judge asks for a live walkthrough, run the commands
in `docs/USAGE.md` and record that instead - they take about two minutes and spend six
cents of test USDC.

Scenes, in order: the problem, what Tina does, price the decision, who serves the intents,
the test suite, the paid listing run, the memo, the evidence check, the signal lookup, the
yield workflow refusing a single source, the mining workflow, spend and replay, how to
try it, and the four workflows.

To re-record it live instead, follow `docs/USAGE.md` with a screen recorder running. That
is the better artifact if you have two minutes: it is a real session, not a render.
